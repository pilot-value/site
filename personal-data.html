取得するデータの一覧

データ種別
内容・目的

メールアドレス

会員登録・ログイン認証に使用。お知らせメールの配信は既定でオフで、ご自身でオンにしたときだけお送りします。

メール配信の設定

配信をオンにしたかどうか・オンにした日時・配信停止用のトークン・最後にメールをお送りした月、および直近に明細を出した日とそこから推定した給料日。給料日は国や会社によって違う（日本は25日ごろ、湾岸は月末、米国は月2回）ため、送信日を固定せず、この推定値を使っています。

ユーザー名

コミュニティ上の表示名として使用。実名である必要はありません。

閲覧ログ

サービス改善・不正利用防止のためのアクセス解析に使用。個人を特定しない形で処理。

Cookie / LocalStorage

テーマ設定（ダーク/ライト）等のユーザー設定を保存。認証セッションの維持に使用。

投稿コンテンツ

コミュニティへの投稿・コメント。利用規約に違反する場合は削除対象。

給与明細の画像

自動入力のために解析するときだけ使います。送信されるのはご本人が確認した「送る枠」の中だけです。枠の外は、送信前にお使いの端末の中で画像ごと切り落とされ、端末を出ることはありません。枠は給与の表に合わせて自動で置き、ご自身で動かしていただけます。さらに枠の中についても、氏名・社員番号・口座番号を端末の中で自動で探して黒く塗り、塗ったうえでご確認いただいてから送信します（塗る前の画像が端末を出ることはありません）。自動の検出は取りこぼすことがあるため、送信前にご自身でご確認いただく画面を挟んでいます。PDF を落としていただいた場合も、端末の中で1ページ目だけを画像にしてから同じ手順を通します（2ページ目以降は送られません）。画像はサーバのメモリ上で読み取るだけで、ストレージにもデータベースにも保存せず、ログにも残しません。読み取りが終わり次第、破棄されます。

給与レポート

金額・時間・会社などの投稿内容。誰が投稿したかを結び付けずに保存します（アカウントIDそのものではなく、復元できないハッシュで重複投稿だけを判定しています）。統計値の算出に使用します。

IPアドレス（ハッシュ化）

明細の読み取り回数の上限（未ログインは1日1回）を数えるためだけに使います。IPアドレスそのものは保存せず、復元できないハッシュに変換して30日間だけ保持し、その後削除します。

メールでのお知らせについて

  • お送りする相手：マイページで「月次リマインド」をオンにした方だけです。既定はオフで、オンにしていない限り一通もお送りしません。
  • 頻度：多くても月に一度です。同じ月に二通は送りません。給料日を過ぎていて、その月の明細がまだ出ていないときにだけお送りします。
  • 書いてあること：データ解放の残り日数・連続提出月数・累計枚数と、マイページへのリンクだけです。
  • 書いていないこと：金額は一切書きません。会社名・機材・職位・明細の項目名も書きません。メールは受信箱と送信事業者のログに残るため、報酬に関わる数字はログインの向こう側だけに置いています。
  • 止めかた：メール本文いちばん下の「配信を停止する」を押すと、その場で止まります（ログイン不要・一度押すだけです）。マイページのスイッチを戻しても同じく止まります。どちらの操作も即時に反映され、以後お送りしません。

データの保持期間

  • 会員アカウントデータ：退会申請後30日以内に削除
  • アクセスログ：最大90日間保持後に削除
  • コミュニティ投稿：退会後も匿名化した形で残存する場合があります
  • 給与明細の画像：保存しません（読み取り後ただちに破棄）
  • 回数制限用のハッシュ化IPアドレス：30日後に削除
  • メール配信の設定：退会時に削除（同意した日時は、同意をいただいた証跡として退会まで保持します）

データの海外移転

当サイトは日本国内を主な運営基盤としています。サービス提供にあたり、一部のデータ処理が海外のサーバーで行われる場合があります。その際は適切な保護措置を講じます。

具体的には、次の処理で海外の事業者を利用しています。

  • 給与明細の読み取り：Anthropic 社（米国）の API に、ご本人が確認した「送る枠」の中だけを送って解析します。枠の外は端末を出ません（送信前に端末の中で画像ごと切り落としています）。枠の中の黒塗りも端末側で画素に焼き込んでから送ります。画像は解析のためだけに送られ、当サイトでは保存しません。
  • 口コミの翻訳：同社の API に投稿本文を送って日英に翻訳します。
  • 認証・データベース：Supabase 社のサービスを利用しています。
  • メールの送信：Resend 社（米国）を利用しています。送信のため、メールアドレスと本文が同社を経由します（本文に金額・会社名は含めていません）。

データ削除の申請

ご自身のデータの削除・開示を希望される場合は、プロフィールページの退会申請フォームまたはコミュニティページのお問い合わせよりご連絡ください。本人確認の後、速やかに対応いたします。

未成年者のデータ

当サイトは18歳未満の方を対象としておりません。18歳未満の方が誤って登録された場合は、速やかにお知らせください。
